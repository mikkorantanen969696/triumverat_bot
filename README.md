# 🏢 Система управления клининговой компанией

## 📋 Описание проекта

Комплексная система для автоматизации управления клининговой компанией через Telegram бот. Платформа объединяет администраторов, менеджеров и клинеров в единую рабочую среду с полным контролем бизнес-процессов.

## 🚀 Ключевые возможности

### 👑 Для администратора
- Полное управление системой
- Управление менеджерами и паролями
- Детальная статистика по всему бизнесу
- Финансовый контроль и аналитика
- Выгрузка данных в различных форматах

### 👔 Для менеджера
- Создание и управление заявками
- Автоматическая генерация счетов с QR кодами
- Взаимодействие с клиентами и клинерами
- Просмотр своей статистики
- Оплата услуг клинеров

### 👨‍🔧 Для клинера
- Принятие заявок в своем городе
- Фотофиксация работы (ДО/ПОСЛЕ)
- Получение оплаты на карту
- Управление реквизитами
- Отслеживание заработка

## 🛠️ Технологический стек

- **Python 3.11** - основной язык программирования
- **PostgreSQL** - реляционная база данных
- **aiogram 3.4** - фреймворк для Telegram ботов
- **SQLAlchemy** - ORM для работы с БД
- **ReportLab** - генерация PDF документов
- **QR Code** - создание QR кодов для оплаты

## 🚀 Быстрый старт

### 1. Клонирование и установка
```bash
git clone <repository-url>
cd triumphverat_bot
pip install -r requirements.txt
```

### 2. Настройка конфигурации
```bash
cp .env.example .env
# Отредактируйте .env файл с вашими данными
```

### 3. Инициализация базы данных
```bash
python init_db.py
```

### 4. Запуск бота
```bash
python run_bot.py
```

## ⚙️ Настройка

### 1. Telegram Bot Token
Получите токен у [@BotFather](https://t.me/BotFather) и добавьте в `.env`:
```env
BOT_TOKEN=YOUR_BOT_TOKEN_HERE
```

### 2. База данных PostgreSQL
Настройте подключение к PostgreSQL в `.env`:
```env
DATABASE_URL=postgresql+asyncpg://user:password@host:port/database_name
```

### 3. Администраторы и менеджеры
В файле `config.py` добавьте:
- ID администраторов и их пароли
- ID менеджеров и их пароли
- ID подтем для городов в Telegram группе

## 🎯 Бизнес-процесс

1. **Клиент обращается** к менеджеру по любому каналу
2. **Менеджер создает заявку** в Telegram боте
3. **Заявка появляется** в соответствующем городе
4. **Клинер принимает заявку** и получает контакты менеджера
5. **Клинер выполняет работу** с фотофиксацией ДО/ПОСЛЕ
6. **Менеджер проверяет работу** и оплачивает услуги клинера
7. **Клиент оплачивает услугу** по QR коду из счета
