# 📋 ИНСТРУКЦИЯ ДЛЯ АДМИНИСТРАТОРА

## 🔐 Вход в систему

1. Найдите бота в Telegram и нажмите **"Start"**
2. Введите ваш **администраторский пароль**
3. После успешной авторизации вы попадете в главное меню администратора

## 👑 Основные функции администратора

### 👥 Управление менеджерами

#### ➕ Добавление менеджера:
1. Нажмите **"👥 Управление менеджерами"**
2. Выберите **"➕ Добавить менеджера"**
3. Введите **Telegram ID** нового менеджера
4. Введите **username** менеджера (без @)
5. Придумайте и введите **пароль** для менеджера
6. Сообщите менеджеру его пароль для входа

#### ➖ Удаление менеджера:
1. Нажмите **"👥 Управление менеджерами"**
2. Выберите **"➖ Удалить менеджера"**
3. Введите **Telegram ID** менеджера для удаления
4. Подтвердите действие

### 📊 Статистика и аналитика

#### Полная статистика:
- **📊 Полная статистика** - вся информация по бизнесу
  - Общее количество заявок
  - Выполненные заявки
  - Общая выручка
  - Статистика по менеджерам
  - Статистика по городам
  - Статистика по клинерам

#### Детальная статистика:
- **📈 Статистика по менеджерам** - эффективность каждого менеджера
- **🏙️ Статистика по городам** - популярность городов и выручка
- **👨‍🔧 Статистика по клинерам** - загруженность и заработок клинеров

### 📋 Управление заявками

#### Создание заявки:
1. Нажмите **"📋 Создать заявку"**
2. Следуйте пошаговой инструкции:
   - 🏙️ Выберите город
   - 🏠 Введите адрес
   - 👤 Введите имя клиента
   - 📞 Введите телефон клиента
   - 📅 Укажите дату и время
   - 🧹 Выберите тип уборки
   - ⏱️ Укажите продолжительность
   - 💰 Укажите стоимость
   - 🔧 Наличие оборудования
   - 🧽 Наличие моющих средств
   - 📝 Дополнительная информация

### 💰 Финансовое управление

#### Управление платежами:
- **💰 Оплатить клинеру** - выплата заработанного клинерам
- **💳 Получить оплату от клиента** - фиксация поступлений
- **📊 История платежей** - просмотр всех финансовых операций

#### Выгрузка данных:
- **📊 Excel** - полный отчет в Excel формате
- **📄 CSV** - данные в CSV для анализа
- **📋 JSON** - структурированные данные
- **📈 PDF отчет** - готовый отчет для печати

### ⚙️ Настройки системы

В меню настроек вы можете:
- Управлять городами
- Настраивать комиссии
- Редактировать реквизиты компании
- Создавать резервные копии

## 🚨 Важные моменты

### Безопасность:
- Никогда не передавайте свой пароль третьим лицам
- Регулярно меняйте пароли менеджеров
- Следите за активностью менеджеров

### Мониторинг:
- Ежедневно проверяйте статистику
- Контролируйте работу менеджеров
- Отслеживайте финансовые потоки

### Резервное копирование:
- Регулярно выгружайте данные
- Храните копии в надежном месте
- Проверяйте целостность данных

## 📞 Поддержка

При возникновении проблем:
1. Проверьте логи в файле `logs/bot.log`
2. Перезапустите бота при необходимости
3. Свяжитесь с разработчиком системы
