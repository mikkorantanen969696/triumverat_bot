# 📋 ИНСТРУКЦИЯ ДЛЯ МЕНЕДЖЕРА

## 🔐 Вход в систему

1. Найдите бота в Telegram и нажмите **"Start"**
2. Введите ваш **менеджерский пароль**, который выдал администратор
3. После успешной авторизации вы попадете в главное меню менеджера

## 👔 Основные функции менеджера

### 📋 Создание заявок

#### Пошаговый процесс создания заявки:

1. Нажмите **"📋 Создать заявку"**
2. **🏙️ Выберите город** из списка доступных
3. **🏠 Введите адрес** уборки (полный адрес с индексом)
4. **👤 Введите имя клиента** (полное имя)
5. **📞 Введите телефон клиента** (в формате +7XXXXXXXXXX)
6. **📅 Укажите дату и время** (формат: ДД.ММ.ГГГГ ЧЧ:ММ)
7. **🧹 Выберите тип уборки:**
   - 🧹 Регулярная уборка
   - 🏠 Генеральная уборка
   - 🔨 После ремонта
   - 🪟 Мытье окон
   - 👔 Химчистка
8. **⏱️ Укажите продолжительность** (в часах)
9. **💰 Укажите стоимость** (в рублях)
10. **🔧 Оборудование на месте?** (Да/Нет)
11. **🧽 Моющие средства на месте?** (Да/Нет)
12. **📝 Дополнительная информация** (необязательно)

### 📊 Статистика

#### Моя статистика:
- **📊 Моя статистика** - просмотр вашей эффективности
  - Общее количество созданных заявок
  - Количество выполненных заявок
  - Общая выручка
  - Последние заявки

#### Детализация:
- Статистика за разные периоды
- Анализ эффективности
- Сравнение с другими менеджерами

### 💳 Работа с клиентами

#### Создание счета:
1. Выберите заявку
2. Нажмите **"💳 Создать счет"**
3. Система автоматически сгенерирует:
   - PDF счет с QR кодом
   - Реквизиты компании
   - Детали заказа

#### Отправка счета клиенту:
- Счет отправляется автоматически клиенту
- Клиент может оплатить по QR коду
- Оплата фиксируется в системе

### 💰 Финансовые операции

#### Оплата клинеров:
1. Нажмите **"💰 Оплатить клинеру"**
2. Выберите выполненную заявку
3. Подтвердите выплату
4. Оплата фиксируется в системе

#### Просмотр реквизитов:
- **"💳 Реквизиты"** - реквизиты компании для счетов
- Все реквизиты автоматически подставляются в счета

### 📤 Выгрузка отчетов

#### Доступные форматы:
- **📊 Excel** - детальная статистика
- **📄 CSV** - данные для анализа
- **📋 JSON** - структурированные данные
- **📈 PDF отчет** - готовый отчет

## 🚨 Важные моменты

### Ограничения:
- Менеджер видит только свои заявки
- Нет доступа к полной статистике компании
- Нельзя удалять других менеджеров

### Ответственность:
- Качество созданных заявок
- Корректность данных
- Своевременность операций

## 📞 Поддержка

При возникновении проблем:
1. Свяжитесь с администратором системы
2. Опишите проблему детально
3. Приложите скриншоты ошибок

## 🔑 Пароль

- Пароль выдается администратором
- Храните пароль в надежном месте
- При утере пароля обращайтесь к администратору

## 📱 Быстрые команды

- `/start` - перезапуск бота
- Все действия выполняются через кнопки меню
