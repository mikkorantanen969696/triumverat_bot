# 🏢 СИСТЕМА УПРАВЛЕНИЯ КЛИНИНГОМ

## 📋 Общее описание

Система предназначена для автоматизации управления клининговой компанией через Telegram бот. Платформа объединяет администраторов, менеджеров и клинеров в единую рабочую среду.

## 👥 Роли в системе

### 👑 Администратор
- Полное управление системой
- Управление менеджерами
- Просмотр всей статистики
- Финансовый контроль
- Выгрузка данных

### 👔 Менеджер
- Создание заявок
- Взаимодействие с клиентами
- Создание счетов
- Оплата клинеров
- Просмотр своей статистики

### 👨‍🔧 Клинер
- Принятие заявок
- Выполнение уборки
- Фотофиксация работы
- Получение оплаты
- Управление реквизитами

### 🏠 Клиент
- Заказ услуг через менеджера
- Оплата услуг
- Получение фотоотчетов

## 🔄 Бизнес-процесс

### 📞 Канал привлечения клиентов
1. Клиент обращается через различные каналы (Авито, телефон, сайт)
2. Менеджер обрабатывает заявку
3. Создается заявка в системе

### 🤖 Работа в Telegram
1. Менеджер создает заявку в боте
2. Заявка появляется в соответствующем городе
3. Клинеры видят и принимают заявки
4. Происходит выполнение работ с фотофиксацией
5. Менеджер проверяет и оплачивает работу

### 💰 Финансовый поток
1. Клиент оплачивает услугу
2. Менеджер создает счет
3. После выполнения клинер получает оплату
4. Все операции фиксируются в системе

## 🛠️ Технологический стек

- **Python 3.11** - основной язык программирования
- **PostgreSQL** - база данных
- **aiogram 3.4** - Telegram бот фреймворк
- **SQLAlchemy** - ORM для работы с БД
- **ReportLab** - генерация PDF счетов
- **QR Code** - создание QR кодов для оплаты
